# Vidhaven for Windows

Download videos and audio from YouTube, Facebook, Instagram, TikTok, X and 1,000+ sites, in 14 languages.

## Download

1. Open the [latest release](https://github.com/Truth009/vidhaven-releases/releases/latest).
2. Download **Vidhaven-Setup-x.y.z.exe** and run it.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

Already installed? Vidhaven updates itself. When a new version is ready you'll see **Restart to update**.

## Vidhaven Pro

4K / 8K video, 320 kbps MP3, whole playlists and 4 downloads at once. In the app, click **Get Pro**, or message [@Vidhavenpro_Bot](https://t.me/Vidhavenpro_Bot) on Telegram.
